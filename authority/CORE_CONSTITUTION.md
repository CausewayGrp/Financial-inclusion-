# Core Constitution

## Purpose

This constitution defines durable rules for **Yemen Financial Inclusion Evidence / أدلة الشمول المالي في اليمن**. It does not contain mutable factual state and never overrides the Production Master.

## Production authority

The sole production authority is `Yemen_Financial_Inclusion_Evidence_Master.xlsx` in this folder. It governs evidence, claim meaning, source state, rights, controlled-product state and publication state. Every JSON file, Page Spec, SQLite database, static page, prompt, design contract and implementation artifact is subordinate.

If a material defect is found, correct the Production Master first and regenerate its projections. Never repair a public claim only in the frontend or create a parallel source of truth.

## Evidence discipline

1. Preserve the unit: people, households, firms, accounts, active accounts, customers, beneficiaries, transactions, devices, agents and providers are not interchangeable.
2. Preserve the inclusion state: access, ownership, registration, adoption, use, activity, quality, protection, resilience and outcome are distinct.
3. Preserve the universe, denominator/calculation base, geography, observation period, method and source role.
4. Infrastructure does not establish use. A rule does not establish implementation. A licence or listing does not establish operation. A target does not establish achievement. A programme KPI does not establish national prevalence.
5. Missing does not mean zero. Restricted does not mean missing. Technical failure does not mean evidence absence.
6. Different evidence clocks may be read together, but they must not be collapsed into a single implied current state.
7. Disagreement is inspectable evidence. Do not silently average, harmonize or repair it.
8. Derived analysis must be reproducible from governed inputs and transformations.

## Public product doctrine

The public experience is **UNDERSTAND → EXPLORE → VERIFY**.

A consequential claim should travel as **ANSWER → SCOPE → BOUNDARY → VERIFY**.

The product starts from decision questions, not a dataset catalogue. It makes uncertainty and missing evidence useful by connecting them to a Measurement Agenda.

## Source Reference Closure

Every substantive public claim, evidence object, visual and Reading must close to its canonical evidence, dependency/lineage, Source Library record, original locator/authority, rights/publication state and public citation behavior. CauseWay attribution for synthesis or derivation is separate from attribution to the original publisher.

Public citation, factual use and redistribution are separate permissions. A public URL is never treated as a redistribution licence by default.

## Bilingual authority

Arabic and English are co-authoritative public editions over the same stable objects and release state. Either language may be drafted first, but neither is a subordinate translation. Numbers, units, periods, universes, certainty, limitations, rights and change triggers must remain semantically invariant.

## Product boundary

Financial inclusion is the organising question. Macro-financial, institutional, humanitarian, conflict, programme, payments, remittance and regulatory context belongs in the public system only when it materially changes interpretation of a financial-inclusion question, evidence boundary or measurement need.

The product is not a generic Yemen financial-system observatory, a provider ranking, an unofficial strategy, or a CauseWay marketing site.

## Release discipline

Repository completeness is not live-release approval. Live public release additionally requires browser/runtime acceptance, mobile and RTL acceptance, accessibility testing, publication filtering, source-reference closure, security/privacy configuration, rights/legal checks where applicable, correction/version behavior and named release approval.

## Counterfactual deletion test

For every route, visual, Reading, section or tool: if removing it loses no material user value, merge or remove it.

For every material change ask:
- What becomes more true?
- What becomes more complex?
- What can now be removed?
