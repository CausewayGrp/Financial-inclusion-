## Non-negotiable build sequence for design recipient
1. Read plain-language product context and create its own explicit to-do/dependency map.
2. Establish visual/system grammar before beautifying Home.
3. Prove the system on the hardest dense, sparse, verification, editorial and reference pages.
4. Complete Arabic/English, RTL/LTR, mobile and accessibility behavior as first-class design work.
5. Produce a repository-backed design specification; Figma is a visual artifact, not the only implementation contract.
6. Hand Code a deterministic prompt and code handoff that binds every component to governed content fields.
7. Code uses the linked GitHub repository as the implementation repository, builds the complete React static runtime, tests it, and leaves explicit placeholders only for hosting/domain/secrets/analytics/reporting configuration that a developer must supply.








## Counterfactual deletion test
If removing a route, visual, Reading, section, control or handoff artifact loses no material user value, evidence integrity, safety, rights, law or implementation determinism, merge or remove it.
