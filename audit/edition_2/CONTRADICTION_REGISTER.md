# Contradiction register (edition 2, lead 5)

Pairs of governed values that disagree, each built only from governed records (the record ID is the authority; no value is
copied here). Type: **revision** (same item, same period, a later edition prints another value), **source-internal** (one
document disagrees with itself), **universe** (different populations or units), **vintage** (different periods presented
together), **method** (different compilers or concepts), **label** (a table's label does not match its values).
