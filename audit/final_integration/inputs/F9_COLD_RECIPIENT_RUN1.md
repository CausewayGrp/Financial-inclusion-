# F9 cold-recipient run 1 — Claude Design dry run on a clone of main at b96e306 (report as delivered; only this title line added)

Repository: `cleanroom/repo`, a git clone of `CausewayGrp/Financial-inclusion-` at `main` `b96e306`. The working tree was clean before and after. I only read files and ran read-only commands. I ran the README_FIRST §8 gate set in a scratch copy, which I have since deleted. I did not search the web.

## Verdict

**Could a cold Design recipient start D0 without asking anything? Yes, with qualifications.** Setting aside the deliberate status-line hold, the start point is unambiguous and the authority hashes verify (Master `ed3c5796…`, Page Specs `2407cb4f…`, logo `5830163d…`). Every command in README_FIRST §8 exists and passes in a git clone: checksums (720 files), `PROJECTION CHECK PASS`, 288 HTML files built, literal audit 12,760/0 unresolved, `WEBSITE REPOSITORY VALIDATION PASS`, public tools 25/26 (1 not applicable), viewport 168/168, bilingual invariance 0. All 286 localized inventory documents exist, and all 13 journeys resolve with direct links in both languages. D0 (dependency map, plan, escalations) needs no outside answer. But the D0 map cannot be built correctly "from the inventory" as the brief says (M2, M3), and two of the twelve hard-state cases do not resolve to their stated data (M4, M5). Several contradictions would become questions by D1–D2. The main one is how the reference implementation can coexist with gates and suites that are hard-wired to `dist/` and forbid any `<svg>` or `<canvas>` there (M1). The others are the Compare contract, the report-issue destination, fonts, and which projections may be rendered. A recipient given the F9 ZIP instead of a clone hits a failing `validate.py` before doing any work (M12). No finding is a BLOCKER for D0.

**Status line (expected, not a defect).** Line 1 of `handoff/README_FIRST.md` reads "STATUS: **R8.6 FREEZE CANDIDATE — PENDING FINAL CLEAN-ROOM ACCEPTANCE.** Do not start Design until this line reads **DESIGN HANDOFF READY**." The Design prompt, AGENTS.md rule 7 and CONTRIBUTING §8 repeat it.
